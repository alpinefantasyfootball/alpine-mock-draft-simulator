Privacy Policy

What Juke does and doesn't do with anything of yours

Juke has no accounts, no sign-up and nowhere to enter a password, an email address or a card number — there has never been a form on this site that asks for any of them. What follows is a complete, specific account of what the app actually does, not a template filled in with the usual disclaimers.

This is a first version, written to describe what the code actually does rather than to read like a generic policy — every claim below was checked against the source and the live configuration before being written down. It hasn't been reviewed by a lawyer. Last updated 21 August 2026.

01A mock draft on your own

Drafting solo, the whole app runs in your browser and nothing about your draft is sent to a server at all — there is no server in that path to send it to. The board, the projections, the scoring and the grade are all computed on your own machine from files the page already downloaded.

Your progress — the seat you picked, every pick made, your league settings, your queue and watchlist, and any draft you've finished — is written to your browser's own local storage (localStorage), on your device only. Juke has no way to read it back, because there is nowhere for it to be read back from except the browser it was written on. Clearing your browser's site data deletes it permanently, the same as clearing it for any other site.

02Drafting with your league

Sending an invite link creates a shared room, and a room is the one case where drafting does involve a server — everyone in it has to agree on what happened, which your browser alone can't arbitrate. While that room is open, it holds:

  • who's sitting in which seat, and the display name each person typed in;
  • every pick that's been made;
  • the chat messages sent in that room.

There's still no account behind any of this. Your browser generates a random id the first time you join a room, stored the same way as everything in section 01, and that id is what the room uses to tell you apart from the person in the next seat — it isn't tied to your name, an email address, or anything else about you.

A room isn't kept forever. Once every participant has been disconnected for six hours, the room and everything in it — seats, picks, chat, display names — is deleted automatically.

03What your browser talks to directly

A few things load straight from someone else's server, the same way an embedded video or a web font does on most sites — that server sees the request come from your browser directly, including your IP address, the same as it would for any site using it:

Player photosSleeper's own image server, linked directly rather than copied onto ours.
Live scoresESPN's public scoreboard, only fetched while there are games actually being played.
FontsGoogle Fonts (Barlow Condensed, Inter, Archivo).

None of these get anything from Juke beyond the ordinary fact that your browser asked for a file — no draft data, no room data, nothing you've typed.

04What goes through Juke's own server

Two things are proxied through Juke's server instead of being called directly, specifically so the provider's own access key never has to sit in a page your browser can read:

  • Player news headlines, from Tank01 — fetched when you open a player's sheet, cached briefly (fifteen minutes) so the same headline isn't fetched fresh from the provider every time.
  • GIF search in room chat, from GIPHY — only if you actually search for one.

Both requests carry Juke's own server as the visible caller, not your browser, and neither is told anything about you beyond what's needed to answer that one request (a player id, or a search term).

05Hosting, and Cloudflare's own analytics

The site is hosted on Cloudflare, which sees the same standard request information — your IP address, browser and the page requested — that any hosting provider sees for any site it serves. Separately, Cloudflare injects its own Web Analytics beacon into every page on this site to measure real-world load times and errors. That beacon is Cloudflare's, added at their network edge rather than by anything in Juke's own code; it doesn't use cookies and isn't the kind of beacon that follows you across other, unrelated sites.

06What we never collect

  • No sign-up, no password, no email address — there is no form anywhere in the app that asks for one.
  • No payment information. Juke is free and nothing in it is for sale.
  • No advertising trackers, and nothing here is sold or shared with anyone for marketing.
  • No location data beyond the coarse, IP-level location any web request already carries.

07Cookies

Juke's own code sets none. Everything in sections 01 and 02 is held in local storage, which is not a cookie and is never sent to a server automatically the way a cookie is — it only leaves your browser when the app deliberately sends it, as in a room.

08Children

Juke isn't directed at children and isn't built to identify anyone's age — there's no sign-up to ask at. It's a fantasy football tool, built with an adult fantasy-football audience in mind.

09Changes to this page

If what the app actually does changes, this page changes with it — the same rule the rest of the app follows: nothing here should describe a version of Juke that no longer exists. The date at the top moves when it does.
