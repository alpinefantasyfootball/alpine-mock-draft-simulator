The palette is unchanged

Same three colours you already had. What changed is that #002F3F is no longer a fill inside the mark — in the supplied art the eyes, teeth and jaw were painted the canvas colour, so the logo only worked on that one background. Every theme now declares its own negative value.

One caution: Steel #1A6386 measures 2.19:1 on deep teal. It is a fill, not a UI colour — don't let it carry text, icons or borders.
